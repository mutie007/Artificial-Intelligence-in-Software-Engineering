# AI Dynamic Web Lab Generation for Core CSS Concepts

This folder contains the interactive single-file HTML labs generated using AI (Gemini) for learning core CSS concepts.

## Files

- `box-model-lab.html` → Refined Box Model interactive lab (with side-specific controls)
- `flexbox-grid-playground.html` → Flexbox and Grid interactive playground

## AI Tool Used
Google Gemini (Canvas)

## Description
These labs were created through sequential prompting to help visualize the CSS Box Model and modern layout systems (Flexbox/Grid).
